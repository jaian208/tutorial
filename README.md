# Tienda Gaming - Condicionales en EJS

Este proyecto es una aplicación web desarrollada con Node.js, Express y EJS 
que demuestra el uso de condicionales dentro de vistas para mostrar contenido dinámico.

## Descripción

La aplicación muestra una lista de productos y utiliza un condicional en EJS
para visualizar un mensaje especial cuando el stock de un producto es igual a 1.

Ejemplo:
> Última unidad

Esto permite simular un comportamiento común en tiendas online.

##  Instalación

1. Clonar el repositorio:

git clone https://github.com/jaian208/tutorial


2. Entrar al proyecto:

3. Instalar dependencias:

npm install express
npm install ejs

---

## Ejecución

Ejecutar el servidor con:


node app.js


Luego abrir en el navegador:


http://localhost:300


---

## Funcionalidad principal

- Listado dinámico de productos
- Uso de `forEach` en EJS
- Uso de condicional `if` para validar stock
- Separación de vistas en archivos parciales
